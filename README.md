# Linked List Implementation (Java)

## Description
Custom singly linked list built from scratch without using built-in data structures.

## Features
- Add items
- Remove items
- Search functionality
- Update item data

## Concepts Used
- Nodes and references
- Traversal
- Pointer management

## Status
Completed.

## How to Run

1. Navigate to the src folder:
   cd src

2. Compile:
   javac linkedlist/*.java

3. Run:
   java linkedlist.Main
